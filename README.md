🌶️ Spice Garden - Food Menu

A simple and attractive Food Menu webpage created using HTML.

🍽️ About the Project

Spice Garden is a basic restaurant food menu website that displays different food and drink options along with their prices and descriptions.

The menu includes:

- 🥗 Starters
- 🍛 Main Course
- 🍰 Desserts
- 🥤 Drinks
- 📞 Contact Information

🛠️ Technologies Used

- HTML5

📂 Project Structure

food-menu/
└── index.html

✨ Features

- Simple restaurant-style menu
- Different food categories
- Food descriptions and prices
- Navigation links
- Contact information
- Beginner-friendly HTML project
